# CSVインポート バリデーション修正チェックリスト

行1〜4で同じバリデーションが出ている場合、**列のずれ**か**値の表記違い**が原因です。以下を順に確認してください。

---

## 1. まず確認：ヘッダー行と列数

- **1行目は必ずシステムのヘッダーと完全同一**にしてください。管理画面の「テンプレートCSV」をダウンロードし、その1行目をそのまま使うのが確実です。
- ヘッダーが1字でも違う・順序が違う・列が足りないと、**すべての列で値がずれ**、一斉に「Invalid option」になります。

**期待するヘッダー（この順の29列）：**

```
ID,送信日時,どの通信制高校についての口コミですか？（学校名）,あなたの立場,状況,卒業後の進路,卒業後の進路（その他）,通信制を選んだ理由,在籍していたコース,入学タイミング,入学年,主な通学頻度,主に通っていたキャンパス都道府県,授業スタイル,生徒の雰囲気,その他（生徒の雰囲気）,学びの柔軟さ（評価）,先生・職員の対応（評価）,心や体調の波・不安などに対するサポート（評価）,在校生の雰囲気が自分に合っていたか（評価）,単位取得のしやすさ（評価）,独自授業・コースの充実度（評価）,進路サポート（評価）,行事やキャンパスライフの過ごしやすさ（評価）,学費の納得感（評価）,総合満足度,良かった点（自由記述）,改善してほしい点/合わない点（自由記述）,メールアドレス
```

- Excelで編集した場合、**列の挿入・削除**をしていないか確認。
- セル内に**カンマ（,）・改行・ダブルクォート（"）**があると、その列以降がずれます。該当する場合はセルを `"..."` で囲み、内部の `"` は `""` にエスケープしてください。

---

## 2. 各項目の「許容される値」（1字一句同じにすること）

| 項目（ヘッダー名） | 許容される値（このどれかだけ） |
|-------------------|--------------------------------|
| **あなたの立場** | `本人` または `保護者` |
| **状況** | `在籍中` または `卒業した` または `以前在籍していた（転校・退学など）` |
| **入学タイミング** | `新入学（中学卒業後）` または `転入学（他校から転校）` または `編入学（中退後に入り直し）` |
| **入学年** | 半角数字4桁のみ。例: `2024`（`2024年`・`R6`・全角は不可） |
| **主な通学頻度** | `週5` または `週3〜4` または `週1〜2` または `月1〜数回` または `ほぼオンライン/自宅` |
| **学びの柔軟さ（評価）** など 1〜5 の評価 | `1` または `2` または `3` または `4` または `5`（半角数字の文字列。`1.0` や ` 1 ` は不可） |
| **独自授業・コースの充実度（評価）** など 1〜6 の評価 | `1` 〜 `6` のいずれか（半角） |
| **総合満足度** | `1` 〜 `5` のいずれか（半角） |
| **メールアドレス** | 半角の `@` を含む有効な形式。全角＠は不可（インポート時に半角へ置換する処理あり） |

---

## 3. よくある原因と修正

| 現象 | 原因 | 修正 |
|------|------|------|
| 全項目で Invalid option | ヘッダーが違う／列がずれている | テンプレートCSVのヘッダーをそのまま使い、列の追加・削除をしない |
| 入学年エラー | `2024年`・全角`２０２４`・`R6` など | 半角4桁だけにする（`2024`） |
| 主な通学頻度エラー | `月1～月数回`・`週3-4` など | 値は `月1〜数回`・`週3〜4`（**〜は U+301C の波ダッシュ**）。`～`（全角）や `-` は不可 |
| 評価がすべてエラー | Excelで数値の 1,2,3 にしている | 文字列の `1` `2` `3` にする。セル書式を「文字列」に |
| 評価がすべてエラー | 空白・未入力 | 必須なので 1〜5 または 1〜6 のいずれかを入力 |
| メールエラー | 全角＠・空・形式違い | 半角 `@` のメール形式で入力（空は不可） |

---

## 4. 推奨手順

1. 管理画面から**テンプレートCSVをダウンロード**する。
2. そのファイルの**1行目（ヘッダー）は一切変更しない**。
3. 2行目以降にだけデータを入力し、上表の**許容される値**をコピペで入れる。
4. 保存時は **UTF-8（BOM付き推奨）** で保存する。
5. 再度インポートして、行1〜4のエラーが解消しているか確認する。

---

## 5. 波ダッシュについて

「主な通学頻度」などで使う **〜** は、次の1種類だけ有効です。

- **有効**: `〜`（Unicode U+301C、波ダッシュ）
- **無効**: `～`（U+FF5E 全角チルダ）・`-`（ハイフン）・`ー`（長音）

見た目が似ていても別文字なので、**エクスポートCSVや本ドキュメントの値をそのままコピー**して使ってください。
