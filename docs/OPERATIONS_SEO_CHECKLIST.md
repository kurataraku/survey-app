# SEO対策 運用担当者向け作業リスト

検索結果やSNSシェアをより効果的にするため、**管理画面で実施していただく作業**をまとめました。技術的な変更は開発側で対応済みです。以下の運用のみご対応ください。

---

## 1. 学校のメタを設定する（AI要約）

**目的**  
学校詳細ページがGoogleなどで検索されたとき、共通の「〇〇の口コミ・評判」ではなく、**その学校ごとのメタタイトル・メタ説明**が表示されるようにする。

**どこでやるか**  
管理画面 → **学校管理** → **学校一覧** → 対象の学校の **編集** → 下にスクロールした **「AI要約」** のブロック。

**手順**

1. 管理画面にログインする。
2. **学校管理** → **学校一覧** を開き、メタを設定したい学校の **編集** をクリックする。
3. 学校編集ページで下へスクロールし、 **「AI要約」** を表示する。
4. **「AI要約を生成」** をクリックする。  
   - 口コミがある学校では、要約・**メタタイトル**・**メタ説明**の案が自動作成される。  
   - 口コミがまだない学校は生成できない場合がある。口コミが増えたら再度実行する。
5. 表示された **メタタイトル**・**メタ説明**を確認し、必要なら手で修正する。  
   - 検索結果にそのまま出るので、**学校名**や**「口コミ」「評判」**などのキーワードを入れるとよい。
6. **「下書きを保存」** をクリックして保存する。
7. 問題なければ **「公開」** をクリックして要約を公開する。

**誰が・いつ**  
運営担当者。**学校を追加したあと**、または**既存の学校でメタが未設定のものを洗い出したあと**、計画的に実施する。

---

## 2. 学校のスラッグを適切に設定する

**目的**  
学校詳細のURL（例: `.../schools/n-koukou-kuchikomi`）に使う **スラッグ** は、検索エンジンにもユーザーにも伝わるため、SEOに影響します。  
「N高校」「n-kou」「n-koukou-kuchikomi」のように表記がバラバラだと、どのURLがどの学校か分かりにくく、統一感も欠けます。**ルールを決めて運用**することが望ましいです。

**どこでやるか**  
管理画面 → **学校管理** → **学校一覧** → 対象の **編集** → **「スラッグ」** の入力欄。

**運用のポイント**

| 項目 | 内容 |
|------|------|
| **使う文字** | **英小文字・数字・ハイフン（`-`）のみ**にするとよいです。日本語（例: N高校）はURLでエンコードされ長くなり、共有しづらくなります。 |
| **表記のルール** | 学校名をローマ字や略称で表し、**サイト内でルールを統一**するとよいです。例: `n-koukou-kuchikomi`（N高）, `s-koukou`（S高）。略称だけ（`n-kou`）でも動きますが、もう少し分かる形（`n-koukou-...`）のほうがURLの意味が伝わりやすいです。 |
| **重複** | スラッグは**学校ごとに1つずつ、重複不可**です。保存時にシステムでチェックされます。 |
| **変更** | スラッグを変えると**URLが変わり**、旧URLは 404 になります。検索結果やブックマークのリンクが壊れるため、**新規登録時にきちんと決めて、あとから安易に変えない**でください。どうしても変える場合は、開発・運営責任者に **旧URL→新URLのリダイレクト設定** を依頼してください。 |

**誰が・いつ**  
運営担当者。**学校を新規追加するとき**に、上記ルールに沿ってスラッグを設定する。既存校は、よほど問題がなければ変更しない。

## 3. 特集記事のメタ・抜粋・アイキャッチを埋める

**目的**  
特集記事の検索結果のタイトル・説明、およびSNSシェア時の画像を、**記事ごとに適切な内容**にする。

**どこでやるか**  
管理画面 → **記事管理** → **新規作成** または 該当記事の **編集** → **「SEO設定」** と **抜粋・アイキャッチ** の入力欄。

**やること（4つ）**

| 項目 | 何に使われるか | 運用のポイント |
|------|----------------|----------------|
| **メタタイトル** | 検索結果のタイトル | 記事の内容が分かり、キーワードを含める。未入力の場合は「記事タイトル」が使われる。 |
| **メタ説明** | 検索結果の説明文 | 未入力の場合は「抜粋」が使われる。 |
| **抜粋** | 一覧・詳細の表示のほか、メタ説明の代わりにも使用 | 短い要約を書く。 |
| **アイキャッチ画像** | 記事詳細の画像のほか、SNSシェア時の画像（OGP） | 未設定ならデフォルト画像になるが、記事ごとの画像があると効果的。 |

**誰が・いつ**  
記事の投稿・更新をする担当者。**新規公開前**と、**既存記事の見直し時**に実施する。

## 4. 知っておいてほしいこと（slug とメタの関係）

- **URL用の slug**  
  - 学校・記事のURL（例: `.../schools/学校のslug`, `.../features/記事のslug`）やサイトマップで使う識別子です。  
  - **学校**のスラッグはSEOにも影響するため、ルールを決めて設定することが望ましいです。くわしくは **2. 学校のスラッグを適切に設定する** を参照。  
  - **記事**のスラッグは、運用ではこれまでどおり設定・管理していればOKです。変更のときは重複に注意してください。

- **検索結果のタイトル（メタ）**  
  - 検索結果に表示される「青いリンクのタイトル」は、**メタタイトル**または**記事タイトル**から作られます。**slug は使いません。**  
  - 運用で大切なのは、**メタタイトル・記事タイトルをきちんと入力・管理すること**です。slug をメタ用にいじる必要はありません。

## 5. 口コミがまだ少ない学校（学校紹介・AI・CSVで情報を厚くする）

**目的**  
口コミ件数が少ない学校でも、**学校紹介（intro）・ハイライト・AI生成のSEO/FAQ** で比較に耐えるページにする。都道府県検索・学校名検索での有用性を高めます。

**どこでやるか**

| 手段 | 場所・コマンド |
|------|----------------|
| 手入力・編集 | 管理画面 → **学校管理** → 学校 **編集** → 学校紹介文・タグ（ハイライト） |
| AI一括（学校ページ用） | 開発向け: `npx tsx scripts/agent-setup.ts --school-id=<uuid> --publish=false` 等（`CLAUDE.md` の AI エージェント節を参照）。公開は管理画面の AI 要約から **公開** を実行。 |
| CSV 一括 | `npm run seed:schools`（`scripts/seedSchoolsFromCsv.ts` の前提に沿った CSV） |

**運用のポイント**

- 口コミがない学校では、**評判の断定は書かず**、学習形態・サポート・公式確認の促しに寄せる。  
- 学校追加のたびに **intro** を可能な範囲で埋める。  
- カバレッジ確認: `npm run seo:coverage`（全体）、`npx tsx scripts/seo-coverage.ts --prefecture-coverage`（**都道府県別・口コミ0件校**の intro / highlights / 公開済み SEO・FAQ の件数）。  
- 大量更新後は `docs/INDEXNOW_PLAN.md` に沿い **IndexNow** を検討。
