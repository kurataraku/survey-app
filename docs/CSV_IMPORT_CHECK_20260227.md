### 3. 主な通学頻度（バリデーションで弾かれる主原因）

- **原因**: システムが受け付けるのは **波ダッシュ `〜`（Unicode U+301C）** のみ。  
  CSV では **半角チルダ `~`（U+007E）** や **全角チルダ `～`（U+FF5E）** になっていると「Invalid option」になる。
- **該当例**:
  - `週3~4` → 期待値は `週3〜4`
  - `週1~2` → 期待値は `週1〜2`
  - `月1～月数回` → 期待値は `月1〜数回`（〜は波ダッシュ、文言は「数回」）
- **対応**: インポート処理側で **`~` と `～` を `〜` に置換**し、**「月数回」を「数回」に置換**する正規化を入れました。  
  既存CSVを修正する場合は、該当セルを上記の期待値に合わせてください。
